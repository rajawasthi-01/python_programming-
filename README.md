## ▶️ How to Run

1. Install Python on your computer.
2. Clone this repository:

```bash
git clone https://github.com/rajawasthi-01/python_programming-.git
```

3. Open the repository in VS Code or any Python IDE.
4. Run a Python program using:

```bash
python filename.py
```

## 💻 Example

```python
a = int(input("Enter a: "))
b = int(input("Enter b: "))

sum = a + b

print("Sum =", sum)
```

```text

Enter b: 20
Sum = 30
```
